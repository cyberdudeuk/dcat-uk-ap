    1.2.0-rc.1, 2026-11-06Updated

    • Renamed DCAT-AP-UK, the DCAT Application Profile for the UK, after the naming of other national profiles (ADR 0011). The namespace is now https://w3id.org/dcat-ap-uk/.
    • Display options in the masthead, beside search and help: theme, text size, spacing, contrast, motion and link style.
    • A user guide, guided tours on seven pages and six tutorials with progress.
    • The metadata weaver: convert between seven input and nine output formats, with every field threaded, and the crosswalk matrix. DDI Codebook joins the crosswalks.
    • The lineage explorer, a standards map of about 60 related standards, and insights: charts of the profile, each with a table.
    • Integrations: a conformance kit with expected verdicts, level badges, a command line, a local HTTP API and a GitHub Action.
    • Avoiding lock-in and technical debt, with model contract clauses to download.
    • From the xGov MEM: a class diagram on each class page, a value types page, the profile in tables on the home page, a licence page and "Suggest a change to this page" in every footer.
    • A visual site map, colour by section and more icons.
    • A requirements stream: requirements from cross-government engagement and public sources, by theme, layer (L0 to L4) and status, traced from evidence to release, with release gates and a proposed work programme (ADR 0015).
    • The weaver reads Apache Atlas entities, the model behind the Microsoft Purview data map, and invents nothing: every gap becomes a note. A candidate geodesy module adds reference frame, epoch, technique and uncertainty.
    • Catalogue records can carry their own security classification, and any record can say why a property is empty, with a reason from a list based on the GML and INSPIRE nil reasons (missing value, rule Q-02).
    • Harvested catalogue records can point to the record they came from and list what they enriched. The geospatial extension adds representation type and OGC service conformance.
    • The generated LinkML file is now checked with LinkML's own tools, and agrees with the other three validators.
    • Reuse across government: standards, models, registers, catalogues and toolkits that fit with the profile, the Data Standards Authority's endorsed standards (now one-press suggestions in the builder) and a real-world test of the 2023 Data Marketplace records.
    • Checked at source: current versions of the standards, the organisation list after the July 2026 machinery of government change, and UK adequacy, now called data bridges.
    • New and Updated flags on every changed section, drawer item and group, under each page title and in the global bar, with the full list above, and a Status page with the self-checks that run on every build (ADR 0016).

    1.1.0-rc.1, 2026-11-06

    • Nine sector extensions (health, geospatial, statistics, transport, high-value datasets, AI-ready, data spaces, private and voluntary sector, energy), each with its own shapes, schema, example and break.
    • Cross-border flows: where data is held or sent, across the UK nations, Crown Dependencies, Overseas Territories, Commonwealth and partners, and the UK GDPR transfer safeguard (rule R-08).
    • A quality score on the five EU quality dimensions and three conformance levels, in the builder, the checker and the new bulk checker.
    • AI-ready: usage policies in ODRL, schema.org and Croissant exports, llms.txt and an MCP server. Quantum-ready: strong checksums, connection security and crypto-agility.
    • An adoption toolkit: routes by sector, a checklist, crosswalks (CKAN, Dublin Core, UK GEMINI, HDR UK, Croissant, DCAT-AP and DCAT-US), harvesting, contract clauses and organisation identifiers.
    • A scan of DCAT profiles around the world, and an OpenAPI to data service converter.
    • Linked to the future pan-UK metadata architecture it implements.

    1.0.0-rc.1, 2026-11-06

    • First release candidate of DCAT-AP-UK, evolved from the xGov MEM v0.1.0.
    • Profile, codelists, shapes, schema, context and examples generated from one source.
    • Portal with record builder, validator and xGov MEM conversion, crosswalks, backlog register, strategy, roles, knowledge layer, estate comparison and governance.
    • Joined the estate compass as its South bearing.
