    Recommended properties

    Identifier dct:identifier

    The main identifier of the resource in the publisher's own catalogue.

    Obligation
    Recommended
    Cardinality
    0..1
    IRI
    dct:identifier
    Value
    literal
    Why it matters
    Lets systems tell records apart, avoid duplicates and link to the same resource across catalogues.
    Not to be confused with
    The record's web address (its IRI), which should also be stable, and other identifiers (use "other identifier").
    How to fill it in
    Use an identifier that will not change, even if the resource moves or the organisation is reorganised. Opaque, non-sequential identifiers are best. Do not reuse an identifier for a different resource.
    Example
    2dfb82b4-741a-4b93-807e-11abb4bb0875
    Since the xGov MEM
    Range relaxed. Was restricted to an IRI or CURIE. A plain literal now, as in DCAT, so local catalogue identifiers can be used; the record IRI carries the web identity.
    Also known as
    2026 guidance: identifier; schema.org: identifier K
