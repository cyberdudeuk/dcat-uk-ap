    A harvested catalogue record (synthetic)New

    A record kept by a central catalogue about a dataset it harvested. It points back to the source record, says which value the harvester added, declares the profile it was written to, and carries its own classification and audience, separate from the data's (RQ-03, RQ-08, RQ-25).
