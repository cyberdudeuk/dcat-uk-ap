    About

    Accessibility statement

    This statement applies to the DCAT-AP-UK portal. It is a draft until a manual audit has been done.

    Using this portal

    We want as many people as possible to be able to use this portal. You should be able to:

    • change colours, contrast levels and fonts using your browser or device settings, and switch between light and dark
    • zoom in up to 400% without the text spilling off the screen
    • navigate the whole portal using just a keyboard or speech recognition software
    • listen to it using a screen reader
    • make text larger, spacing wider and contrast higher, reduce motion and underline links from Display options at the top of every page

    How accessible this portal is

    Every build is checked automatically with axe-core in Chromium, for horizontal overflow at widths from 320 to 1920 pixels, and for colour contrast in light and dark. We know some parts may not be fully accessible:

    • the class diagram and the knowledge graph are complex images; each has a text alternative
    • the record builder has many fields; it has not been tested with screen reader users
    • the portal is in English only
    • it has not been audited manually

    Feedback and contact information

    If you need information in a different format, or you find a problem, use the contact form. If you cannot use the form, ask a colleague to raise it for you. We will reply within 10 working days.

    Enforcement procedure

    This portal is a personal public-good project, not a public sector body's website, so the Public Sector Bodies Accessibility Regulations 2018 may not apply. We follow them anyway. If it were adopted by a public body, the Equality and Human Rights Commission would be responsible for enforcing them.

    Technical information

    We are committed to making this portal accessible, in line with the Public Sector Bodies (Websites and Mobile Applications) (No. 2) Accessibility Regulations 2018.

    Compliance status

    This portal is partially compliant with the Web Content Accessibility Guidelines version 2.2 AA standard, because it has not yet been audited manually.

    Preparation of this statement

    This statement was prepared on 2026-11-06. The portal was last tested automatically on the same date. It will be reviewed by 2027-02-06.
